# Demo script (about 2 minutes)

Use this for the live demo and for the backup screen recording.

| Time | Action | Say |
|---|---|---|
| 0:00 | Page open on the map | "DeepBengal is a marine data viewer for Bangladesh waters. It opens on our maritime zone and nothing else. The dashed outlines are the four marine protected areas." |
| 0:12 | Click inside the boundary | "Clicking the zone opens everything we hold: 26 Copernicus Marine variables from 1993 to 2026, grouped into ocean colour, physics, chemistry and wind." |
| 0:25 | Type "temp" in the search box, pick Temperature | "Every row shows the unit, the years and the source." |
| 0:32 | Drag the month slider across a year, then the depth slider | "The map changes in a fraction of a second without reloading the page. Twelve variables have depth levels, so we can look below the surface." |
| 0:48 | Click a point inside the Swatch of No Ground MPA | "Clicking any pixel opens an inspector like the Copernicus viewer: the value, its 30-year series, the vertical profile and a depth–time section. It tells us this pixel is inside the Swatch of No Ground MPA." |
| 1:08 | Drag the month slider past the last month | "Following our mentor's advice we trained a U-Net for every variable. These are 12-month forecast maps. We tested each model on two hidden years: temperature beat the average-year baseline by 20 percent." |
| 1:25 | Switch to pH | "pH forecasts were the strongest, 32 percent better than the baseline. Where a forecast has no skill, the app says so." |
| 1:35 | Click Download chart data, then Source citation | "Anyone can download the exact data shown, with the Copernicus citation." |
| 1:45 | Open About and methods | "Every product is listed with its DOI, every outside source with its licence, and every forecast with its test score." |
